# V78 — Diagnóstico OAuth 2 (solo lectura)

Subir el contenido del ZIP a la rama `v78-google-test` de GitHub (no a `main`). Ejecutar `Build unsigned iOS IPA`, descargar artefacto e instalar con Sideloadly.

Pulsar **Comprobar credenciales** y compartir una captura. No compartir tokens. Se comprueban Google Userinfo y Drive con el access token y, si está disponible, con `getAuthorizationCode`. No se crean hojas.

**No apta para datos fiscales reales.**
